# CuadernoDocente · v1.0-rc1

Repositorio **privado** para las pruebas de aceptación del cuaderno docente de Latín y Griego.

Esta versión candidata permite realizar pruebas con **alumnado ficticio**, pero no está validada para tratar calificaciones reales. Se han superado 133 pruebas automatizadas; faltan las comprobaciones de Safari en Mac, iPhone e iPad.

El código original se distribuye en `CuadernoDocente_v1.0-rc1.zip` (SHA-256: `105162db702e5205bd307db8f48e9e975b480cf6105ce27eb31ccd72525af6be`).

Para probar en dispositivos Apple, se prevé un despliegue de GitHub Pages tras superar las pruebas del flujo de trabajo. **Advertencia:** la web de GitHub Pages puede ser pública aunque el repositorio sea privado. No introducir datos reales.

Documentación y protocolo completo: `README.md`, `docs/ESTABILIZACION_RC1.md` y `qa/PROTOCOLO_SAFARI.md` dentro del ZIP.
